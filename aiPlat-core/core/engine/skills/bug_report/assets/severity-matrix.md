# 严重程度 × 优先级矩阵

## 严重程度 (Severity)

| 级别 | 定义 | 示例 |
|------|------|------|
| **Blocker** | 阻断核心流程，所有用户不可用 | 登录失败、支付不可用、首页500 |
| **Critical** | 核心功能异常，影响主要业务流程 | 订单创建失败、搜索无结果 |
| **Major** | 功能缺陷，有替代方案 | 导出格式错误、筛选条件失效 |
| **Minor** | 体验问题，不影响功能 | 文字错误、样式偏移 |
| **Trivial** | 建议优化 | 配色建议、文案优化 |

## 优先级 (Priority)

| 级别 | 定义 | 响应时间 |
|------|------|:---:|
| **P0** | 立即修复 | < 2h |
| **P1** | 24小时内 | < 24h |
| **P2** | 本周内 | < 1周 |
| **P3** | 可延后 | — |

## 推断规则

| 现象特征 | 推断环境 | 推断严重程度 |
|------|------|:---:|
| 返回 500 / 502 / 503 | 服务端 | Critical |
| 返回 404 | 客户端 | Major |
| CORS 错误 | 浏览器 | Major |
| Timeout / 连接超时 | 网络或服务端 | Critical |
| 数据丢失/不一致 | 数据库/后端 | Blocker |
| 页面崩溃/白屏 | 前端 | Critical |
| 权限拒绝 | 权限系统 | Major |

# 首切片场景候选（L1 / §2.3）

> **场景类型**：**内部可复现** · 标注 **「非客户验收」**  
> **D13 知悉**：本场景可支持至 Gate 1 与首切片；**Gate 2 扩大前**须真实客户路径替换，或取得符合落地方案 §6.0.1 的书面客户背书（含原件）。  
> **路径方案**：A（本体非必经）— 见落地方案 §3.1  
> **日期**：2026-10-23

| 客户场景 | 否（非客户验收） |

---

## 2. 输入

1. 一个内部 Engagement / Scenario（可用夹具数据，不必真实客户）。  
2. 一份待发布的 **低风险** Agent Bundle 候选（工具以只读/无高风险副作用为默认）。  
3. 一个 **隔离** Pi Thin 目标环境（本地或专用沙箱）。  
4. 预定义：成功输出契约、失败条件、回滚指向（**Bundle 版本优先**，Runtime 备选）。  
5. 夹具锚点（已授权）：`packages/aiplat-pi-runtime/fixtures/sample-app`（见 `DECISIONS_AND_AUTHORIZATIONS.md` A3.4）。  
6. 承诺等级（已授权）：路径目标 **E3**；默认 **非对外承诺**（不要求 E4）。

---

## 3. 预期输出（目标路径 · 非断言现状已通）

```text
FDE：建场景 + 验收标准
  → aiPlat：发布版本化 Agent Bundle（权限声明 + 审计）
  → Pi Thin：隔离环境安装并运行
  → 诊断：接入 Pi + aiPlat 证据，报告可追溯（含 unknown/stale）
  → FDE：接受 / 拒绝或开整改
  → 至少 1 次：断连 / 拒权 / 过期 → 不得伪报成功
```

本体步骤：**本场景默认不启用**（盘点维度标「切片未使用」）。

---

## 4. 失败条件（业务可判定）

任一条成立 → 业务验收 **不通过**（或 WP4 归因后不降标重开）：

| ID | 失败条件 |
|----|----------|
| F1 | 无法从 FDE 需求追溯到 Bundle 版本 → Pi 实例 → 诊断报告 |
| F2 | 无授权调用未被目标服务拒绝，或仅靠 Pi 客户端 gate「通过」 |
| F3 | 缺证据仍报 healthy/成功 |
| F4 | 控制面/证据断连时高风险副作用未 fail-closed（首切片应无高风险工具） |
| F5 | 无法按预定回滚 Bundle 或 Runtime |

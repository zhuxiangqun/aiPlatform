# Pi Thin 离线策略（本切片 · WP2 草案）

> **状态**：草案 v0 · 2026-10-23  
> **依据**：落地方案 §3.5 / D6b；授权 A2.3  
> **范围**：已签名 Bundle **落盘后**的执行阶段；**不包括** Bundle 发布与诊断查 aiPlat 证据。

| 字段 | 本切片取值 |
|------|------------|
| `offline_max_ttl` | **24h**（自上次成功 Bundle/策略完整性校验起）；无撤销通道时实际按 **12h** 执行（见 revocation） |
| `allowed_ops_offline` | 只读 / 低风险技能与工具；夹具 `sample-app` 声明内集合；**⊆** 无高风险副作用 |
| `denied_ops_offline` | 写生产、跨租户、密钥导出、任意 shell、heal/自动修复、未声明工具 |
| `bundle_expiry / policy_expiry` | 过期 → **停止执行**（非「降级只读继续」）；须重新在线校验或换包 |
| `revocation` | 首切片 **无**在线撤销列表通道 → 默认缩短 TTL 为 12h；一旦曾在线拉取撤销列表，离线期满必须重新校验 |
| `audit_buffer` | 本地缓冲上限 **1000** 条或 **10MB**（先到为准）；恢复上送失败 → 诊断/报告记 `stale`/`unknown`，**禁止**标成功 |

## 与 aiPlat 在线依赖（对照）

| 阶段 | 依赖 aiPlat 在线 |
|------|:----------------:|
| 发布 Bundle | 是 |
| 安装/加载已签名包 | 否 |
| 执行允许的离线闭环 | 可离线（本文件） |
| 诊断查 aiPlat 侧证据 | 是（断连记缺口） |

## 验收指向（Gate1 后 WP4）

断连超过 TTL、调用 denied 类、过期包继续跑 → 必须失败或 unknown，不得伪报成功。

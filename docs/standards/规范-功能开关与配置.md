# 规范-功能开关与配置（AIPLAT_* 环境变量）

## 1. 目的

aiPlat 有 **49 个默认关闭（`"false"`）的 opt-in 功能开关**。部署方若不知晓，能力会**静默不生效**（P0-B5）。本文档是全部 opt-in 开关的权威参考——**新增默认 false 的 `AIPLAT_*` 开关时，必须在本文件登记**（防再次出现"能力静默"）。

## 3. 规则

1. **登记义务**：新增默认 `"false"` 的 `AIPLAT_*` 开关，必须在本文件对应分组登记（用途 + 位置），否则视为"能力静默"违规（P0-B5）。
2. **行为配置归属**：超时/阈值/开关等行为配置用环境变量或 YAML（`config.yaml`/`PipelineStageConfig`），`.env` 仅用于凭据（贡献红线 §21-2）。
3. **生产建议**：
   - 安全类（`SKILL_INSTALL_REQUIRE_*`、`SELF_HEAL_AUTO`=false、`SYSCALL_ENFORCE_APPROVAL`）生产默认开启或保持 review-first
   - 开发类（`PLATFORM_DEV_*`、`APPROVALS_DISABLED`、`MOCK_SEARCH_ENABLED`）生产禁止开启
   - 可观测类（`OTEL_ENABLED`）按监控需求开启
4. **验证**：新增开关后 `grep -c 'AIPLAT_新开关' docs/standards/规范-功能开关与配置.md` ≥1。

# 规范-数据与数据库（Schema 归属 / 迁移 / 命名）


## 1. Schema 归属（强制）

| 层 | Schema 位置 | 说明 |
|----|------------|------|
| core（Harness 内核） | `core/schemas_*.py` 按域拆分 | Pydantic 模型；`core/schemas.py` 仅做兼容 re-export |
| core 持久化 | `core/services/execution_store/` + `schema.py` 迁移 | 运行时 DB 表 |
| platform | `apps/{module}/api/schemas*.py` 或 `apps/common_schemas.py` | API 响应模型 |
| infra | `infra/{module}/schemas.py` | 基础设施数据模型 |

**禁止**：
- 业务表定义放在 infra 层（如 `tenant_quotas` 曾放错层——历史违规）
- `schemas.py` 巨型聚合（应按域拆 `schemas_*.py`）
- 在 router/API 层直接执行 DDL

## 2. 迁移机制（强制）

- 所有表结构变更走 **版本化迁移**：`core/services/execution_store/schema.py` 的 `run_migrations(conn, current, target)`
- 每个迁移块：`if current < N:` + 幂等 SQL + `_set_version(N)`
- **幂等性**（v46 executescript 崩溃教训）：
  - `CREATE TABLE` 必须 `IF NOT EXISTS`
  - `ALTER TABLE ADD COLUMN` 必须包 `try/except sqlite3.OperationalError: pass  # noqa: schema-idempotent`
  - **禁止** `conn.executescript()` 批量执行含 ALTER 的脚本（隐式提交 + 无法按条捕获错误）

## 3. 命名规范

| 对象 | 规则 | 示例 |
|------|------|------|
| 表 | 小写下划线复数 | `memory_messages`、`approval_requests` |
| 列 | 小写下划线 | `created_at`、`tenant_id` |
| FTS 表 | 主表名 + `_fts` | `memory_messages_fts` |
| 索引 | `idx_{表}_{列}` | `idx_memory_messages_tenant` |
| Schema 版本 | `CURRENT_SCHEMA_VERSION` 单调递增 | 51 → 52 |

## 4. 关键字段约定

| 字段 | 约定 |
|------|------|
| `id` | TEXT 主键（UUID/前缀-ID），如 `msg-{hex}` |
| `created_at` / `updated_at` | REAL（Unix 时间戳）或 ISO8601 TEXT，全库一致 |
| `tenant_id` | 多租户表必须含（WARNING→ERROR 阻断检索） |
| `status` | 枚举字符串（`enabled/disabled/deprecated` 等），前端不依赖中文 |
| `metadata` | JSON TEXT 存储扩展字段（不可查询字段） |

## 5. 数据访问

- 统一通过 `core/services/execution_store`（单例工厂 `get_execution_store()`）访问运行时 DB
- **禁止**各模块自建 `sqlite3.connect` 散落（数据库路径由 env 统一解析）
- 迁移与 DDL 集中在 `schema.py`，业务模块只做 DML

## 6. 验证命令

```bash
# 全新 DB 迁移冒烟
python3 -c "
from core.services.execution_store import ExecutionStore, ExecutionStoreConfig
import asyncio; asyncio.run(ExecutionStore(ExecutionStoreConfig(db_path='/tmp/smoke.sqlite3')).init())
print('migration smoke OK')
"

# 幂等性检查：禁止 executescript 含 ALTER
grep -rn "executescript" aiPlat-core/core/services/execution_store/schema.py | wc -l  # 预期仅 CREATE-only
```

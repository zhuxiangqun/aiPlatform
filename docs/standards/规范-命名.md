# 规范-命名

> 状态：v1.0 (2026-08-16) · 适用：全部代码 · 来源：规范体系审计 P2-B3（命名不一致：docs/docs 嵌套、_facade 重命名等）

## 1. Python

| 对象 | 规则 | 示例 |
|------|------|------|
| 模块/文件 | 小写下划线 | `execution_store.py`、`schemas_builder.py` |
| 类 | PascalCase | `PipelineEngine`、`TrainingStatusResponse` |
| 函数/方法 | 小写下划线 | `build_context()`、`_load_golden_eval_score()` |
| 常量 | 全大写下划线 | `CURRENT_SCHEMA_VERSION` |
| 私有 | 前缀 `_` | `_facade.py`、`_apply_canary_block_approved()` |

**禁止**：`docs/docs` 嵌套、驼峰文件名、中文字符串作为标识符。

## 2. TypeScript / React

| 对象 | 规则 | 示例 |
|------|------|------|
| 组件文件 | PascalCase | `FdeDashboard.tsx` |
| hook | `use` 前缀 | `useWorkspaceAgent()` |
| 类型/接口 | PascalCase | `WorkspaceAgentResponse` |
| 普通文件 | camelCase | `coreApi.ts` |

## 3. 数据库

| 对象 | 规则 | 示例 |
|------|------|------|
| 表 | 小写下划线复数 | `memory_messages` |
| 列 | 小写下划线 | `created_at` |
| FTS | `{表}_fts` | `memory_messages_fts` |
| 索引 | `idx_{表}_{列}` | `idx_memory_messages_tenant` |

## 4. API 端点

- 路径小写 + 连字符或下划线（与 router 一致）：`/api/platform/apps/workbench/specs`
- 禁止中文字符路径

## 5. 环境变量

- 前缀 `AIPLAT_`，全大写下划线：`AIPLAT_EXECUTION_DB_PATH`

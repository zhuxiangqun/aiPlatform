# 规范-独立多租户


## 1. 租户表归属（强制）

| 数据 | 正确位置 | 状态 |
|------|---------|------|
| 租户身份/配额/套餐 | **platform 层**（`TenantManager` 配额存储） | core 的 `tenant_quotas`/`tenant_policies` 已标 DEPRECATED，待迁移 |
| 运行数据隔离 | core `execution_store`（带 `tenant_id` 列） | ✅ |
| 会话/记忆 | core（带 `tenant_id` + `session_id` 隔离） | ✅ |

**禁止**：在 core schema 新增租户管理表（应进 platform）；检索函数缺 `tenant_id`（守卫 WARNING→ERROR 阻断）。

## 2. 隔离要求

| 维度 | 要求 |
|------|------|
| 检索隔离 | `WikiPageRetriever.retrieve()` 等必须带 `tenant_id`，不匹配返回空 |
| 记忆隔离 | `MemoryEntry` 强制 `tenant_id` + `session_id` |
| API 透传 | platform → core 必须注入 `X-AIPLAT-TENANT-ID` 等标准头 |
| 配额 | 通过 platform `TenantManager` 管理，core 不直接写配额表 |

## 3. 权限

- RBAC 角色（admin/developer/operator）由 platform 定义（`ROUTE_PERMISSIONS` 等）
- core 只消费 platform 注入的身份，不自行推断

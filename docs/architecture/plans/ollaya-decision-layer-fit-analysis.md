# aiPlat × Ollaya 决策层适配分析报告

> **类型**：试点评估假设（非实施承诺 / 非性能认证 / **非试点批准书**）  
> **版本**：v1.3 · 2026-11-07（阶段指标时序 + 影子异步/审计边界）  
> **对象**：aiPlat 工作区（core / platform / management / infra）  
> **实施方案（未改程序）**：[ollaya-decision-layer-implementation-plan.md](./ollaya-decision-layer-implementation-plan.md) v1.0  
> **诚实边界**：本报告**不**宣称已集成 Ollaya；**不**预先承诺延迟或业务准确率收益；决策模型**不**替代 PolicyGate、Agent 生成或 Eval live。**代码路径接线 ≠ 真实请求流量已证实。** 影子**不阻塞**主路径，且旁路不改变决策**≠**可无限制复制请求数据。

## 0. 修订后结论（请以此为准）

> aiPlat 存在可探索 typed-decision model 的分类与判定路径。  
> **当前最有代码路径证据的候选是 `DomainRouter` 的 T3 LLM 分类**（`_llm_classify`）。「有调用方」只证明接线，**不**证明当前环境流量、T3 触发率或延迟分布——这些须阶段 0 实测（**仅现网基线**）。  
> **意图路由需先核实实际调用链**：生产主路径调用的是规则版 `classify()`（低置信 → `should_clarify`）；`classify_with_llm` 存在于源码但**未检索到生产调用方**，因此**不能**用「替换线上 LLM fallback」估算延迟/成本节省。  
> Ollaya 适合作为**可选、可关闭的旁路试点**：阶段 1 仅为**异步、有界、可丢弃的影子评分**（**不 await 决策服务**；失败/超时/排队满直接跳过；**不参与** `DomainRouter.classify()` 返回值）。影子模型自身的 P50/P95 **在阶段 1 运行后**才记录，不作为进入影子的前置门槛。离线与影子证据达标后，**另开评估**是否进入替换路径。  
> **现阶段不替代 PolicyGate**，不接管 Agent 生成或 Eval live，也**不预先承诺**性能或业务准确率收益。本文件**不等于**试点批准或性能结论。  
> **四子仓检索未发现 Ollaya 引用**（见附录 B）；不等于全 git 工作区每个目录都扫过。

| 判断 | 等级 |
|------|------|
| 架构方向（决策运行时 ≠ 生成运行时；旁路建议信号） | **基本正确** |
| 「四子仓检索未发现 Ollaya 引用」 | **有检索证据**（见附录 B） |
| 「DomainRouter T3 可试点」 | **有代码路径证据**；现网流量/T3 延迟待阶段 0；影子延迟待阶段 1 |
| 「意图 Classifier 是首选替换点 / 省掉 LLM fallback」 | **降级**：实现存在、生产接线未证实 |
| 「概率可校准 / 秒变毫秒」 | **待验证假设**，非产品保证 |
| 「入口安全作 P0 拦截」 | **过高** → 改为影子评分，晚于分类路由 |
| 「影子模式」 | **阶段 1 强制**：异步有界、不阻塞、不改路由结果；须有审计/脱敏策略 |

## 1. Ollaya 是什么（与 Ollama 的边界）

| 维度 | Ollama | Ollaya |
|------|--------|--------|
| 产品定位 | 本地运行**生成式 LLM** | 本地运行**typed-decision models**（官方定位） |
| 典型 I/O | Prompt → 文本/代码 | 状态 + 类型化问题 → 选项 / 分数 / 概率 |
| 与本仓现状 | **已探测 / 用于本地预检**（模型目录扫描、本地冒烟可用性检查等；**≠** 主运行链已全面接入 Ollama） | **四子仓检索未发现引用**（见附录 B） |

**措辞约束（v1.1+）**：

- 宜说：Ollaya **定位于**运行决策类模型，**适合**固定选项、打分、yes/no 等形态。  
- 不宜说：「决策模型不能生成文本」作为对一切模型的普遍断言；也不宜把「输出概率」直接写成「已校准」。  
- 官方材料称 typed answers 与概率、毫秒级场景（见 [FAQ](https://ollaya.dev/docs/faq)、[Quickstart](https://ollaya.dev/docs/quickstart)）；**任意任务/语言/硬件上的校准与延迟均须本机复测**。

## 2. 仓库现状地图（证据分层）

图例：

- **E1 已核实代码路径**（定义 + 源码中存在生产/近生产**调用点**）

### 2.1 E1 — 最有代码路径证据的候选：DomainRouter T3

| 项 | 内容 |
|----|------|
| 位置 | `aiPlat-core/core/harness/knowledge/domain_router.py` |
| 现状 | T1 标签；T2 embedding 余弦；T3 `_llm_classify`（文件头注释写 ~300ms，**注释量级 ≠ 实测**） |
| 调用点（E1） | `classify()` 内可进入 T3；源码调用方含 materials_chat、retrieval、context_bus、skills/registry 等 |
| 流量（未证实） | **未知**：调用点存在 ≠ 现网 QPS、T3 占比、冷启动频率、P50/P95；**阶段 0 必测** |
| 为何可探索 Ollaya | T3 是「标签/向量不够 → LLM 选域」的选择题形态 |
| **旁路路径（阶段 1，默认）** | 主路径跑完现网 T1→T2→T3 并**立即返回** `domain_id`；影子任务**异步投递**（有界队列 + 超时 + 采样率），对进入 T3 / T2 边界带的样本打分；结果只写审计日志/指标；**禁止**同步 await 决策服务；失败/超时/排队满/服务不可用 → **丢弃本次影子**，现网零影响 |
| **替换路径（阶段 1b，另评估）** | 仅当离线标注 + 影子对照达标，且有特征开关与回滚方案时，才评估「用决策结果替代 T3 输出」；**不得**与阶段 1 影子混称为「影子替换」 |
| 收益（H） | 若未来进入替换路径，**或**可减少 T3 生成式调用；须同负载对照；不得预先写成「一定 &lt;100ms」 |

## 3. 为什么值得探索（动机，非承诺）

结构性观察（E1/E2）：部分路径在「规则/向量不够」时求助于生成式 LLM 做枚举选择（DomainRouter T3 已证实；意图 LLM 路径有实现无接线）。

探索价值在于：用更贴近「固定选项」的运行时做**可开关旁路**，并保留降级。

**不是**因为已证明 Ollaya 在本仓更快、更准或已校准。

## 4. 收益表述规范（全部标为假设 H）

| 场景 | 现状证据 | 接入后说法（允许） | 禁止写法 |
|------|----------|-------------------|----------|

### 指标时间顺序（v1.3 强制）

| 时点 | 可测指标 | 不可测 / 不得作为门槛 |
|------|----------|----------------------|
| **阶段 0**（进入影子前） | 现网 `classify` 调用量；T1/T2/T3 命中占比；**现网 T3** P50/P95（冷启动单列）；意图 LLM 是否接线 | 影子模型延迟；「接入后一定更快」 |
| **阶段 1**（影子运行中） | 影子任务投递率/丢弃率/超时率；影子 vs 现网域一致率；**影子推理** P50/P95；资源争用观察 | 把影子延迟倒写进阶段 0 准入 |
| **阶段 1b 评估前** | 阶段 0+1 全套 + 离线标注准确率/校准（若宣称） | 无回滚方案的替换 |

本机对照最低要求：

**阶段 0（准入影子实验）**

1. **现网流量基线**：`DomainRouter.classify` 调用量、T1/T2/T3 命中占比  
2. **现网 T3 延迟基线**：P50 / P95；冷启动单独列  
3. 意图路由：确认是否启用 `classify_with_llm`  
4. 影子实现方案书面确认：异步、有界、可丢弃、超时、采样率（见下节）  
5. 影子审计/脱敏策略书面确认（见 §5.1）

**阶段 1（运行后记录，非准入前置）**

1. 影子延迟 P50/P95、丢弃/超时占比  
2. 与现网 `domain_id` / T3 结果一致率  
3. 离线标注集上的准确率；若谈校准则加可靠性图

## 5. 分阶段试点（修订优先级）

```
阶段 0  证据门（准入影子实验）——只测现网
        - DomainRouter：调用量、T1/T2/T3 命中率、现网 T3 P50/P95
        - 意图路由：确认是否启用 classify_with_llm；无则勿写 LLM 节省叙事
        - 影子工程约束与审计方案评审通过（仍不启动影子流量）

阶段 1  DomainRouter 旁路影子（首选，默认终点未定）
        - 特征开关默认关；采样率可配（建议先低采样）
        - 主路径：现网 classify 正常返回，零等待影子
        - 影子：异步有界队列；超时/满载/服务不可用 → 丢弃
        - ★ 不写入 classify() 返回值；禁止同步 await 决策服务
        - 本阶段才开始记录影子 P50/P95 与一致率
        - 同步建设离线域分类标注集

阶段 1b 替换路径评估（可选，另开变更；≠ 阶段 1）
        - 仅当阶段 0 现网基线 + 阶段 1 影子证据达标
        - 特征开关 + 金丝雀 + 一键回滚到纯 T1/T2/T3
        - 文案禁止再称「影子替换」

阶段 2  意图路由（仅当阶段 0 证实有 LLM 热路径，或明确要新增强决策分流）
        - 同样先异步影子、后评估替换；低置信保持 clarify

阶段 3  PolicyGate 风险影子分
        - 只写建议字段；权限唯一点不变

阶段 4  安全/注入影子（最晚）
        - 人工标注 + 误报漏报达标前不得拦截
```

### 5.1 影子执行边界（阶段 1 强制）

| 要求 | 说明 |
|------|------|
| **不阻塞** | `classify()` 返回路径上不得 await / 同步 RPC 决策服务 |
| **异步投递** | fire-and-forget 或有界队列；队列满 → 丢弃并计 `shadow_drop_queue_full` |
| **超时** | 单次影子推理硬超时（建议配置化）；超时计 `shadow_drop_timeout`，不重试阻塞主路径 |
| **采样** | 默认低采样率；可按 tier（仅 T3 / T2 边界带）收窄 |
| **失败可丢弃** | 服务不可达、反序列化失败、过载 → 跳过；**禁止**回压到请求线程 |
| **不改决策** | 影子输出不得写入返回的 `domain_id` 或下游检索集合选择 |

### 5.2 影子审计与隐私最小集（阶段 1 强制）

旁路不改变决策，**不**等于可无限制复制请求全文。立项实现须在变更单中固定：

| 项 | 最小约定（可收紧，不可无声明） |
|----|-------------------------------|
| **可记录字段** | 请求 id / 追踪 id；时间戳；现网 `domain_id` 与命中 tier；影子输出选项与概率；影子耗时；模型/运行时版本；采样标记；丢弃原因码 |
| **输入文本** | 默认**脱敏摘要**或哈希 + 长度；全文仅在显式 opt-in 且符合租户数据策略时短期保留 |
| **禁止默认识别** | 不得默认落盘未脱敏的用户原话、密钥、身份标识到影子库 |
| **保留期** | 变更单写明 TTL（建议影子明细短保留；聚合指标可较长） |
| **访问控制** | 影子日志与现网业务库同级或更严的权限；禁止随意导出 |
| **目的限定** | 仅用于对照评估与可靠性分析，不作其他二次用途除非另批 |

**强制约束**（各阶段通用）：

1. 阶段 1：Ollaya 输出**仅观测**；连建议也不驱动路由  
2. PolicyGate 唯一权限点  
3. 默认关；可灰度；可一键关  
4. 影子失败/丢弃不影响现网；替换路径的降级/fail-closed 须单独书面批准  
5. 能力登记 + 生成物适用性声明（若进入实现）  
6. 影子数据遵守 §5.2 审计/脱敏约定

## 6. 风险

| 风险 | 对策 |
|------|------|
| 把注释延迟当 SLA | 报告与看板一律标「假设 / 待测」 |
| 把调用点当真实流量 | 阶段 0 强制现网调用量 + T3 命中率 + **现网** T3 P50/P95 |
| 把影子延迟写进阶段 0 门槛 | 指标时间表：影子 P50/P95 仅阶段 1 |
| 同步 await「并行」拖慢主路径 | §5.1：异步、有界、超时、可丢弃 |
| 影子无脱敏复制用户原文 | §5.2：字段白名单 + TTL + 访问控制 |
| 把「影子」写成「已替换」 | 阶段 1 / 1b 分文档与开关；阶段 1 禁止改 classify 返回值 |
| 把无 caller 的 LLM 函数当热路径 | 阶段 0 调用链门禁 |
| 安全漏报 | 影子期禁止拦截；阈值按代价设定 |
| 多运行时运维负担 | 健康检查可并列本机 LLM 探测；默认可关 |
| 绕过 PolicyGate | 架构审查 + 仅允许建议字段 |

## 8. 最终建议（行动口径）

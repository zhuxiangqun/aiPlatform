# aiPlat × Ollaya 决策层试点 — 完整实施方案

> **类型**：实施方案（设计 + 工作拆解 + 准入门槛；**本版不改程序**）  
> **版本**：v1.0 · 2026-11-07  
> **状态**：待立项评审 · **≠ 试点批准 · ≠ 性能承诺 · ≠ 已实现**  
> **依据**：[ollaya-decision-layer-fit-analysis.md](./ollaya-decision-layer-fit-analysis.md) **v1.3**（下称「分析报告」）  
> **原则**：先证据、后影子、再评估替换；影子异步有界不阻塞；PolicyGate 唯一权限点不变。

## 1. 目标与非目标

### 1.1 目标（本试点范围）

1. **阶段 0**：用**现网**数据证明 DomainRouter 是否「值得影子」（调用量、T1/T2/T3 命中、现网 T3 延迟）。  
2. **阶段 1**：在 DomainRouter 上接入**可选、默关**的 Ollaya（或兼容 typed-decision HTTP）**异步影子评分**：不改变 `classify()` 返回值；可观测一致率与影子延迟。  
3. **阶段 1 同期**：离线域分类标注集 + 影子审计/脱敏策略落地（配置与存储约定）。  
4. **阶段 1b（可选另案）**：仅当阶段 0+1 达标后，另开变更评估「是否替换 T3」——**不在本方案默认交付范围内自动启动**。

### 1.2 非目标（明确不做）

| 不做 | 原因 |
|------|------|
| 替换 Agent 生成 / ReAct / 代码生成 | 运行时类别不同 |
| 接入 Eval live / 冒烟主路径 | 评测测的是生成式 Agent |
| 阶段 1 同步 await 决策服务 | 会阻塞主路径 |
| 阶段 1 改写 `domain_id` | 违反影子定义 |
| 安全入口拦截（阶段 4 之前） | 漏报代价；分析报告已降级 |
| 宣称意图路由可省线上 LLM | `classify_with_llm` 无生产 caller |
| 绕过 PolicyGate | 架构铁律 |

### 1.3 成功定义（分阶段）

| 阶段 | 「成功」含义 |
|------|----------------|
| 0 | 产出书面基线报告 + Go/No-Go；**不要求**已跑影子 |
| 1 | 影子默认可关；开时不拖慢主路径 P95（相对阶段 0 基线可接受漂移阈值事先约定）；有一致率与丢弃率看板；审计字段符合白名单 |
| 1b | **另案**；本方案只列准入条件，不默认实施 |

## 3. 总体架构（目标态示意，阶段 1）

```
                    ┌─────────────────────────────────────┐
  query ──────────► │ DomainRouter.classify()  (现网不变)  │
                    │  T1 → T2 → T3(_llm_classify)         │
                    │  return domain_id  ◄── 立即返回       │
                    └──────────────┬──────────────────────┘
                                   │ fire-and-forget（采样命中时）
                                   ▼
                    ┌─────────────────────────────────────┐
                    │ ShadowDispatcher（有界队列）           │
                    │  满/关/未采样 → drop + 计数             │
                    └──────────────┬──────────────────────┘
                                   │ 后台 worker（超时硬切）
                                   ▼
                    ┌─────────────────────────────────────┐
                    │ DecisionClient（Ollaya 适配）          │
                    │  typed choice: domain_id candidates   │
                    └──────────────┬──────────────────────┘
                                   │
                                   ▼
                    ┌─────────────────────────────────────┐
                    │ ShadowAuditSink（脱敏字段白名单）      │
                    │  + metrics: latency / agree / drop    │
                    └─────────────────────────────────────┘
```

**硬约束**：上图右侧任何失败都不得回传到左侧返回路径。

### 3.1 建议模块边界（实现期；本版仅设计）

| 模块（建议路径） | 职责 | 层 |
|------------------|------|-----|
| `core/harness/decision_shadow/`（新包，待建） | 队列、采样、超时、丢弃原因码、与 DomainRouter 的钩子 | core |
| `DecisionClient` 协议 + `OllayaHttpClient` | HTTP 调用、健康检查、版本字符串 | core（或薄 infra 客户端，实现期定） |
| 配置：`decision_shadow.yaml` 或 env | 开关、采样、超时、队列、endpoint、TTL | 配置 |
| 指标：`decision_shadow_*` | 投递/丢弃/超时/一致/延迟直方图 | 可观测 |
| **不**放入 | PolicyGate 内决策、Eval 主路径、frontend 业务路由 | — |

**架构合规（实现期自检）**：

- 不硬编码业务域名列表做行为分叉（候选项来自 DomainRouter 已注册域）。  
- 新公共符号同步 `AIPLAT_CAPABILITIES.md` + `capability_registry.yaml`。  
- 生成物适用性：平台横切影子评估 — 标注「生成物不适用：平台路由观测」或按 §23 评估。

### 4.5 Go / No-Go 准则（建议默认，可评审调整）

| 结论 | 条件（示例，立项会可改数字） |
|------|------------------------------|
| **Go 阶段 1** | 观测窗内 T3 命中 ≥ N 次（或占比 ≥ p%），且基线报告完整、§5/§6 方案已批。**建议默认**（证据包 §0.7，立项会可改）：`t3_hits ≥ 100` 或（`t3_llm_pct ≥ 5%` 且 `total ≥ 500`） |

| **意图 LLM 叙事** | 若 0.5 证实无生产 caller → 文档与宣讲**禁止**「省 LLM fallback」 |

## 5. 阶段 1 — DomainRouter 异步影子（默认交付核心）

### 5.1 行为契约（验收用）

| # | 契约 | 验证方式 |
|---|------|----------|
| C1 | `classify()` 返回值与关闭影子时**比特级语义一致**（同输入同配置） | 单测 + 对照回放 |
| C2 | 主路径无 await 决策 HTTP | code review + 超时注入时主路径仍返回 |
| C3 | 队列满 / 超时 / 服务挂 → 仅增 drop 计数，无异常冒泡到调用方 | 故障注入测试 |
| C4 | 特征开关默认 `false` | 配置审查 |
| C5 | 审计字段 ⊆ 白名单；默认无原文 | 抽样日志审查 |
| C6 | 可一键关闭影子（env/配置热更新或进程重启策略写明） | 运维手册演练 |

### 5.2 配置项设计（建议名，实现期可改）

| 配置键 | 默认 | 含义 |
|--------|------|------|
| `decision_shadow.enabled` | `false` | 总开关 |
| `decision_shadow.sample_rate` | `0.01`～`0.05` | 采样率 |
| `decision_shadow.trigger` | `t3_or_t2_boundary` | 何时投递 |
| `decision_shadow.queue_size` | 有界整数 | 满则丢 |
| `decision_shadow.timeout_ms` | 有界 | 单次推理硬超时 |
| `decision_shadow.endpoint` | 空 | Ollaya/兼容服务 |
| `decision_shadow.model` | 空 | 模型名 |
| `decision_shadow.audit_ttl_hours` | 短周期 | 明细保留 |
| `decision_shadow.store_raw_text` | `false` | 全文 opt-in |

行为配置进 YAML；密钥进 env（符合仓库「.env 仅凭据」规约）。

### 5.3 钩子位置（设计）

在 `DomainRouter.classify` **即将 return** 之前：

1. 已算好 `domain_id`、`tier`、可选置信/边距。  
2. 若 `enabled` 且采样命中且 trigger 匹配 → `ShadowDispatcher.try_enqueue(payload)`（非阻塞）。  
3. **立即** `return domain_id`。

禁止：在 `_llm_classify` 内部同步调用决策服务「先影子后返回」。

### 5.4 影子任务 payload（内存态 → 审计前脱敏）

| 字段 | 来源 | 进审计库？ |
|------|------|------------|
| `trace_id` | 上下文 | 是（可哈希） |
| `tier` / `domain_id_online` | classify | 是 |
| `candidates` | 注册域列表 | 是（非隐私） |
| `query_hash` / `query_len` / `query_redacted` | 输入 | 是（按策略） |
| `query_raw` | 输入 | **仅** `store_raw_text=true` |
| `shadow_choice` / `probs` | 决策服务 | 是 |
| `shadow_latency_ms` | 计时 | 是 |
| `model` / `runtime_version` | 客户端 | 是 |
| `drop_reason` | 若丢弃 | 是 |

### 5.5 决策请求语义（typed choice）

- **问题类型**：多选一（domain_id ∈ 当前注册域）。  
- **输入**：脱敏后的 query 摘要 + 可选候选列表。  
- **输出**：选中 `domain_id` + 可选概率分布。  
- **不一致定义**：`shadow_choice != domain_id_online`（T3 样本可另标 `vs_t3`）。

具体 JSON schema 实现期按所选 Ollaya API 定；本方案要求适配层隔离，禁止业务代码散落 HTTP 细节。

### 5.6 指标（阶段 1 起）

| 指标名（建议） | 含义 | 告警建议 |
|----------------|------|----------|
| `decision_shadow_enqueue_total` | 投递尝试 | — |
| `decision_shadow_drop_total{reason}` | 丢弃（queue_full/timeout/disabled/error/…） | queue_full 持续升高 |
| `decision_shadow_agree_total` / `disagree_total` | 与现网一致 | 仅观察，阶段 1 不自动切流 |
| `decision_shadow_latency_ms` | 影子推理延迟直方图 | — |
| `decision_shadow_inflight` | 在途任务 | 触顶告警 |

**主路径**继续用阶段 0 的现网 T3 延迟指标，二者分列，禁止混报成「系统延迟下降」。

### 5.7 离线标注集

| 项 | 要求 |
|----|------|
| 来源 | 历史查询脱敏抽样 + 人工标金标域 |
| 规模 | 立项会定下限（建议先小集可迭代） |
| 用途 | 阶段 1 报告旁路准确率；**阶段 1b 准入** |
| 禁止 | 把影子线上一致率单独当成准确率认证 |

### 5.8 阶段 1 交付物

- [ ] 设计评审通过（已在阶段 0）  
- [ ] 实现变更单（**本方案批准后再写代码**）  
- [ ] 特征开关默关合并  
- [ ] 故障注入证明 C1–C3  
- [ ] 看板：drop / agree / shadow latency  
- [ ] 《阶段 1 运行报告》（含影子 P50/P95、一致率、丢弃率）  
- [ ] 离线标注集 v0 + 评估笔记  

### 5.9 阶段 1 退出条件（进入 1b 评估的门槛，非自动替换）

须**同时**满足（数字由立项会填）：

1. 阶段 0 Go 仍有效（流量未塌缩到无意义）。  
2. 影子运行 ≥ 约定天数；disagree 率与离线准确率达阈值。  
3. drop 率可接受；无主路径回归。  
4. 审计抽检通过。  
5. 书面申请「启动阶段 1b 评估」——**另开文档/变更**。

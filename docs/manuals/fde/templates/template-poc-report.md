| **预期答案** | 硬度 HB 200-230、粗糙度 ≤ Ra 6.3、内径公差 ±0.05、批次号 ZL20260710-CP01 |
| **是否匹配** | ✅ 完全匹配 |
| **准确性** | ✅ 正确 |

#### 问题 2：供应商风险预测

| 维度 | 结果 |
|------|------|
| **输入** | 过去6个月30+供应商交货记录（Excel，约1200行） |
| **AI 输出** | 预测准时率最低三家：① 鑫达钢铁（准时率 72%，主因原材料价格波动）② 华通铸造（准时率 78%，主因产能不足）③ 力成精工（准时率 81%，主因物流不稳定） |
| **预期答案** | 应包含鑫达钢铁和华通铸造在最后两名 |
| **是否匹配** | ✅ 完全匹配 |
| **准确性** | ✅ 正确 |

#### 问题 3：制动噪音诊断

| 维度 | 结果 |
|------|------|
| **输入** | "我们最近一批刹车片（批次 ZL20260701-BP）在冷车低速时出现吱吱声，客户投诉增多" |
| **AI 输出** | 列举了4种可能原因：① 摩擦材料配方比例偏差 ② 消音片安装不到位 ③ 刹车盘表面锈蚀 ④ 卡钳回位不良。给出了排查顺序。但未关联到具体供应商或生产批次。 |
| **预期答案** | 应能关联到摩擦材料供应商（鑫达钢铁的原材料批次），给出更精准的溯源 |
| **是否匹配** | ⚠️ 部分匹配（方向正确，诊断合理，但缺少供应商溯源） |

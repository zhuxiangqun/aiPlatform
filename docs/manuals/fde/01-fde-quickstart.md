# FDE 快速入门（5 分钟）

> ← [文档导航](README.md)

> **目标角色**：第一天加入的 FDE 交付工程师  
> **前置条件**：系统已通过 `./start.sh` 启动

---

## 一句话理解

FDE 工作台是**客户现场的 AI 交付操作系统**。你在左侧选择交付步骤，AI Agent 在右侧自动执行。8 个步骤走完 = 一个客户项目交付完成。

---

## 打开工作台

```
1. ./start.sh                    # 启动所有服务
2. 浏览器打开 http://localhost:5173/diagnostics
3. 点击页面顶部的 "FDE Dashboard"
```

---

## 八步交付流程（你看一遍就懂）

```
① 业务认知  →  ② 评估域  →  ③ 问题重构  →  ④ 验证价值
    选客户         选域           诊断           POC演示

⑤ 快速构建  →  ⑥ 评测护栏  →  ⑦ 验收移交  →  ⑧ 运营监控
   打包部署        灰度测试        客户签收        持续运维
```

Tab 栏上有进度条——完成显示 ✓，当前蓝色高亮，未开始灰色。

---

## 两种工作模式

| 模式 | 什么时候用 |
|------|------|
| **自由模式**（默认） | 非标交付，FDE 手动在 8 个 Tab 间切换 |
| **工作流模式** | 标准交付，4 个 Agent 自动流转，你只需确认关键节点 |

切换方式：标题栏右侧下拉菜单。

---

## 你的第一个交付项目（5 步）

### Step 1：创建客户 Profile
1. 进入 ① 业务认知 Tab
2. 点击右上角 **[+ 新建]**
3. 填写客户名称、描述，选择部署模式（online / airgap / hybrid）
4. 点击确定 → 系统自动推断客户行业

### Step 2：选择域
1. 进入 ② 评估域 Tab
2. 系统自动高亮匹配客户行业的域
3. 点击选择

### Step 3：生成诊断
1. 进入 ③ 问题重构 Tab
2. 输入客户问题描述
3. AI 自动生成诊断报告

### Step 4：POC 验证
1. 进入 ④ 验证价值 Tab
2. 加载行业 POC 模板
3. 注入演示数据（可自动生成）
4. 运行演示

### Step 5：生成交付手册
1. 所有步骤完成后
2. ⑦ 验收移交 Tab → 自动生成交付手册
3. 客户签收确认

## 常用操作速查

| 我想… | 去哪儿 |
|------|------|
| 提交现场反馈 | 右下角浮动反馈按钮 |
| 查看客户健康 | ① 业务认知 → 展开客户卡片 |
| 打包离线部署 | ⑤ 快速构建 → 部署管理 → 打包 |
| 查看交付历史 | ⑧ 运营监控 → 历史诊断 |
| 种子演示数据 | ④ POC Tab → 快速数据注入 |

| 追溯Agent决策链 | 顶部 → 决策血缘（谁选了哪个工具/为什么） |
| 原子拆分任务 | 顶部 → 蜂群推演（自动分解→并行执行→损耗分析） |
| 导出OKF知识格式 | 顶部 → 更多▼ → 编译 → 导出OKF |

| 文档模板渲染 | 顶部 → 更多▼ → 模板（Word/Excel/MD） |

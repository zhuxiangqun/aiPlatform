## 4. 常见问题

| 问题 | 处理 |
|------|------|
| AI 智能填充无反应 | 确认名称和描述至少填了一项 |
| 推荐模型不在列表中 | 检查模型是否已启用：基础设施层 → 模型管理 |
| 推荐 Skill 缺失 | 联系开发团队。FDE 可先跳过 Skill 绑定，Agent 仍可运行（纯 LLM 推理） |
| 创建后 Agent 不显示 | 刷新页面。确认筛选条件未过滤 |
| 自动冒烟失败 | 诊断中心 → Smoke 检查 LLM 连通性 |

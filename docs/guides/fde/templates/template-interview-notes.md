## 三、访谈议题与结论

### 3.1 议题 1：了解核心业务流程

| 维度 | 记录 |
|------|------|
| 客户原话（尽量逐字） | "我们主要给比亚迪、奇瑞供刹车系统零件。每月出货大概300批次，每批都要附质检报告给主机厂。" |
| FDE 追问 | "质检报告现在怎么出的？谁写？" |
| 结论/共识 | 当前质检由3位老师傅手写报告→文员录入Excel→发给主机厂。每月约200份，易出错。 |

### 3.2 议题 2：识别痛点的深层原因

| 维度 | 记录 |
|------|------|
| 客户原话 | "三个老师傅都快退休了，新来的质检员排查一个故障要大半天。最怕的就是老师傅走了以后，再出现制动噪音这类问题没人能判断。" |
| FDE 追问 | "除了人的问题，供应链上有困难吗？" |
| 结论/共识 | 核心痛点是知识断层而非人手不足。供应链方面，30+供应商交期不稳定，常导致产线空置。 |

### 3.3 议题 3：确认技术要求

| 维度 | 记录 |
|------|------|
| 客户原话 | "我们有ERP系统，SQL Server的。生产环境在内网，外网访问要走审批。数据不能出公司。" |
| FDE 追问 | "能接受模型文件打包部署在内网服务器吗？" |
| 结论/共识 | 部署模式确认为 hybrid。质检报告扫描件约5000份可导出。ERP数据需要通过IT配合对接。 |

# FDE 快速入门（5 分钟）

> ← [文档导航](README.md)

> **目标角色**：第一天加入的 FDE 交付工程师  
> **前置条件**：系统已通过 `./start.sh` 启动

---

## 一句话理解

FDE 工作台是**客户现场的 AI 交付操作系统**。选客户 → 生成**交付计划**清单 → 按 ①–⑧（及 ⑥b / ⑨）推进。画面 Tab 以 `FdeDashboard.tsx` 的 `FDE_STEPS` 为准（当前含「交付计划」、⑥b、⑨ 等，不只「八个按钮」）。

---

## 打开工作台

```
1. ./start.sh                    # 启动所有服务
2. 浏览器打开 http://localhost:5173/diagnostics/fde
```

---

## 主路径（你看一遍就懂）

```
① 业务认知 → 【交付计划】→ ② 评估域 → ③ 问题重构 → ④ 验证价值
    选客户      上传/粘贴需求→生成计划   选域         诊断           POC

⑤ 平台离线包 → ⑥ 评测护栏 → ⑥b 上线前检查 → ⑦ 验收移交 → ⑧ 运营监控
                                                    （另有 ⑨ 快速认知）
```

Tab / 进度条：完成 ✓，当前高亮。页顶绿条显示**当前客户**与②已选评估域。

**交付计划要点**（详 [02](./02-fde-delivery.md)）：

- 不依赖 ③ 诊断；一次一个需求文件或粘贴文本 →「生成计划」。
- 清单含 **Gate0**（进场决策手勾）与 **应用工厂并行**（`/app/factory`，不替代 ④–⑦）。
- 计划完成度 ≠ ⑦ 签收；≠ 客户项目交付手册（`fde/manuals`）。

> **⑦「客户签收」≠ Org 组织签收准备**。FDE 签收是**项目交付签收单**。  
> it-ops 组织试点在 **仪表盘 → 组织试点** `/org/pilot`，见 [ORG_L5_RUNBOOK](../../contracts/ORG_L5_RUNBOOK.md)。  
> 建域在 **知识 → 业务本体** `/knowledge/business`，见 [合册](../../contracts/FDE_ONTOLOGY_AGENT_OPS_MANUAL.md)。

## 两种工作模式

| 模式 | 什么时候用 |
|------|------|
| **自由模式**（默认） | 非标交付，在 Tab 间手动切换（含交付计划） |
| **工作流模式** | 标准交付，Agent 自动流转，你确认关键节点 |

切换方式：标题栏右侧下拉菜单。

## 你的第一个交付项目

### Step 1：创建并切换客户 Profile
1. 进入 ① 业务认知 Tab
2. 点击右上角 **[+ 新建]**（或空列表「新建客户」）
3. 填写名称、描述，选择部署模式（online / airgap / hybrid）
4. 创建后点 **切换至此**

### Step 2：生成交付计划
1. 进入 **交付计划** Tab
2. 粘贴需求或上传文本文件（.md/.txt 等，≥20 字）
3. 点 **生成计划**；展开 Gate0，按说明在①写清决策后手勾

### Step 3：选择域
1. 进入 ② 评估域 Tab（全平台域目录；域名≠客户名）
2. 点选本客户交付域

### Step 4：诊断与 POC
1. ③ 问题重构 → 运行诊断并审核
2. ④ 验证价值 → POC；应用工厂可并行推进（计划里「应用工厂并行」）

### Step 5：签收
1. ⑥ / ⑥b 通过后 → ⑦ 验收移交 → 项目签收 / 交付手册
2. ⑧ 运营监控按客户 namespace 过滤

## 常用操作速查

| 我想… | 去哪儿 |
|------|------|
| 提交现场反馈 | 右下角浮动反馈按钮 |
| 查看客户健康 | ① 业务认知 → 展开客户卡片 |
| 打包离线部署 | ⑤ 快速构建 → 部署管理 → 打包 |
| 查看交付历史 | ⑧ 运营监控 → 历史诊断 |
| 种子演示数据 | ④ POC Tab → 快速数据注入 |
| 多场景推演测试 | 顶部 → 沙盒推演（模型切换/跳过阶段） |
| 追溯Agent决策链 | 顶部 → 决策血缘（谁选了哪个工具/为什么） |
| 原子拆分任务 | 顶部 → 蜂群推演（自动分解→并行执行→损耗分析） |
| 导出OKF知识格式 | 顶部 → 更多▼ → 编译 → 导出OKF |
| 录制操作→生成Skill | 顶部 → 更多▼ → 录制（录制→生成→注册） |
| 管理本体分支 | 顶部 → 更多▼ → 本体分支（fork/diff/merge） |
| 查看Agent协作网络 | 顶部 → 更多▼ → Agent网络 |
| 文档模板渲染 | 顶部 → 更多▼ → 模板（Word/Excel/MD） |
| 端到端全链路验证 | API: `POST /api/platform/apps/fde/verify/e2e` |

## 0. 本单是什么 / 不是什么

| 是 | 不是 |
|----|------|
| 交付时的**业务指标基线记录** | 业务 ROI 承诺 |
| 平台侧可观测指标 + 客户侧追踪责任划分 | FDE 替客户算营收 |
| 护航期与退出后的对比起点 | 绩效考核依据 |

**原则：工作台只保证交付链诚实、可审计、可验收。业务结果由客户侧追踪，平台侧只记录基线并观测可观测部分。**

## 1. 指标分类

| 类别 | 定义 | 数据源 | 责任方 |
|------|------|--------|--------|
| P1 平台可观测 | 平台能直接采集 | `action_audit` / canary / Quality Bus | FDE / 平台 |
| P2 客户侧可观测 | 客户系统能采集 | 客户 ERP / CRM / 工单系统 | 客户 |
| P3 联合观测 | 双方数据可交叉验证 | 平台 + 客户 | 共同 |
| P4 客户主观 | 满意度 / 续约意愿 | 客户访谈 | 客户 |

## 3. 使用信号（平台可观测部分）

| 信号 | 数据源 | 健康阈值 | 当前值 |
|------|--------|----------|--------|
| 日活操作人数（S1） | `action_audit.actor` 去重 | ≥ _N_ | _TBD_ |
| Action 日调用量（S2） | `action_audit` 行数 | ≥ _M_ | _TBD_ |
| Action 成功率（S3） | `result_status` | ≥ _Y%_ | _TBD_ |
| 活跃天数（S4） | `created_at` | ≥ _K_/30 | _TBD_ |
| 手工旁路率 | 客户侧 | ≤ _X%_ | _TBD_ / `not-available` |

**说明：** S1–S4 平台可观测（见 [`FDE_USAGE_SIGNAL_MINIMAL_SET.md`](./FDE_USAGE_SIGNAL_MINIMAL_SET.md)）。旁路率需客户配合；不可用标 `not-available`，不作为交付失败依据。平台侧信号长期不达标 → 护航期延长（退出清单 §C）。

## 6. 边界声明

- 本单不承诺业务 ROI。
- 平台侧只保证可观测指标的采集与审计。
- 客户侧指标由客户负责追踪；平台不代客户采集。
- 若客户侧数据不可用，标注 `not-available`，不作为交付失败依据。
- ⑦ 签收通过仅证明**交付质量门**；本单是通向**客户成功指标**的交接物，二者不得混用。

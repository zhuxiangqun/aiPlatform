## 3. 问题与改进（按严重度）

### P1-1 ⚠️ 质量门 `_score_chunk` 中文整段切词缺陷

`retrieval_quality_gate.py:18-25`：`re.findall(r'[\u4e00-\u9fff]+', ...)` ——**连续中文整段匹配为 1 个 token**。

- **实证**：query `"如何实现用户认证"` → 1 个 token `如何实现用户认证`；chunk 含该**完整子串**才得分，否则 0 分
- **影响**：中文场景质量门失真——合法检索结果可能误判 `switch_to_web_search`（`min_chunks<3` 时更激进），或相关性评分无区分度
- **修复**：中文按字 n-gram（如 bigram）或逐字切分（0.5 天）；补中英文混合单测

### P1-2 ⚠️ materials_chat 页面感知检索：业务硬编码 + 全量加载

`materials_chat.py:595`：`WikiPageRetriever(wiki_titles=["manuals / management-ui-operation-manual"], ...)`——**硬编码业务手册名**（违反 CLAUDE.md §8 业务概念不入 core/apps 默认值）。

`wiki_retriever.py:50-58` `_load_pages()`：无 titles 时 `search_pages(limit=1000)` **全量加载内存**——页面感知检索对大 wiki 是内存/延迟风险。

- **修复**：手册 title 配置化（按租户/集合动态发现）；`_load_pages` 改搜索式加载（按 page_label 匹配而非全量）— 1 天

### P2-1 quality gate 仅标记不过滤

`retriever.py:265-275`：CRAG gate 结果只写 `metadata["_quality_gate"]`（action 标记），**不真正降级**（依赖调用方决策）；且 `check_quality` 的 `len(chunks)<3 → switch_to_web_search` 对合法少结果过度激进（`retrieval_quality_gate.py:32-34`）。

- **修复**：gate action 真正驱动检索降级（或阈值配置化）；"chunks<3" 阈值可配置 — 0.5 天

### P2-2 `KnowledgeRetriever.search` 不传 tenant_id

`retriever.py:227`：`KnowledgeQuery(query=..., limit=...)` 无 `tenant_id`——当前唯一调用方是 syscall（`retrieval.py:221` 已注入 `tenant_id=tenant_id`）**无实际泄漏**；但 API 签名缺 tenant 参数，未来直接调用者会落默认 `"default"` 租户库（`sqlite_retriever.py:87`）。

- **修复**：`search()` 增加 `tenant_id: str = ""` 参数并透传 KnowledgeQuery — 0.5 天

### P2-3 摄取 prompt 硬编码

`extractor.py` `EXTRACTION_PROMPT` 硬编码在代码内——违反内容归属规范（"LLM prompt 模板正文 → prompt_loader._register"）；`VALID_CLASS_TYPES`（人物/组织/产品…9 类）硬编码（通用本体可接受，但建议配置化）。

- **修复**：prompt 移入 `prompt_loader` 注册；实体类型改由 ontology YAML 驱动 — 1 天

### P3-1 检索双路径并存

主检索（syscall unified KnowledgeRetriever）+ materials_chat 页面感知（WikiPageRetriever 直连）——同一知识源两条访问路径；建议页面感知增强收敛到 unified 检索（作为 rerank 补充而非独立加载）。

### ⚠️ P0-2 图增强检索**静默失效**（绑定数 bug，实测复现）

`graph.py:126-150` `graph_enhance_query`：SQL 占位符数与参数数**恒不匹配**：

| doc_ids | SQL 占位符 | params | 结果 |
|---|---|---|---|
| `None` | 4（tenant_id + 2×LIKE + LIMIT） | 2（tenant_id + 1×%token%） | **缺 2 → ProgrammingError** |
| 2 个 | 6（+2 占位） | 4 | **缺 2 → ProgrammingError** |

- **实证**：静态数占位符确认恒不匹配（4≠2 / 6≠4）；错误被 `except Exception: return []`（`graph.py:152`）**静默吞掉**
- **影响**：主检索链路 `syscalls/retrieval.py:195` 的图增强文档扩展**从未生效**（`graph_docs` 恒空 → `expanded_ids` 恒等于原 doc_ids）；有 try 保护不崩链路，但功能静默死——与守卫盲区同源（异常被吞 + 无测试覆盖）
- **修复**：补第 2 个 `%token%` 参数 + `LIMIT` 参数；加图检索单测（0.5 天）

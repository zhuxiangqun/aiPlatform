# Decisions（ADR）索引

> v2.4 顶层决策目录。当前迁移期；旧 `docs/architecture/decisions/` 暂时保留。

## 目的

记录已接受的架构、产品、安全、流程决策，采用 ADR 形式：

- 背景；
- 决策；
- 替代方案；
- 后果；
- supersedes / superseded_by。

## 目录

```text
docs/decisions/
  architecture/
  product/
  security/
  process/
```

## 状态

- 本目录为 v2.4 目标结构；
- 现有 ADR 尚未迁移；
- 新增 ADR 应写入本目录对应分类。
